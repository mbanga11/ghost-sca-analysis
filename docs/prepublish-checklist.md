# Pre-publish checklist

## Automated (run the check commands)
- [ ] No Ghost source or node_modules committed
- [ ] No private key blocks anywhere in the repo
- [ ] No unexpectedly large files
- [ ] Numbers in README and report match analysis/findings.csv and the chart script output
- [ ] Pipeline runs end to end without errors

## Manual
- [ ] Charts look right and render in README on GitHub
- [ ] All links in README work (report, deep dives, charts, docs)
- [ ] Deep dives and report revised in my own words
- [ ] Disclaimer present (independent, public advisories only, no new vulns disclosed)
- [ ] LICENSE added for my scripts and docs
- [ ] Make repo public
